# TDS AP2 - Testing Framework

Atividade prática da disciplina Teste de Software do DCC/UFMG.

O objetivo é continuar a implementação de um pequeno framework de testes em Python no estilo xUnit.

## Organização

- `04_classe_testsuite`: implementação da classe `TestSuite` e seus testes.
- `05_classes_testloader_e_testrunner`: implementação das classes `TestLoader` e `TestRunner`.
- `06_executando_todos_os_testes`: execução integrada de todos os testes do framework.
- `07_comandos_assert`: implementação dos comandos `assert_equal`, `assert_true`, `assert_false` e `assert_in`.
